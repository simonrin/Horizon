## [Shopify 将移动应用从 React Native 迁回原生 Swift 和 Kotlin](https://shopify.engineering/back-to-native) ⭐️ 8.0/10

Shopify 宣布将其移动应用从 React Native 迁回完全原生的 Swift 和 Kotlin，公司表示借助 AI 辅助开发，仅用 12 周就完成了从概念验证到完全重建的原生应用并发布到应用商店。 Shopify 的决定是一个重要的行业信号，因为它来自一家规模庞大的电商公司，并为关于 React Native 等跨平台框架是否值得相比完全原生开发做出取舍的广泛争论增添了动力。 据报道，此次迁移得到了 AI 工具的辅助，最终的原生应用在 12 周内发布到了 iOS App Store 和 Google Play；不过，该公司仍拥有约 3000 名工程师，一些社区成员将此视为工程团队臃肿的证据。

hackernews · fnthawar2 · 9月10日 14:09 · [社区讨论](https://news.ycombinator.com/item?id=49643982)

**背景**: React Native 是一个流行的跨平台框架，允许开发者用 JavaScript 编写移动应用并在 iOS 和 Android 之间共享代码，但它在性能和原生功能方面历来存在取舍。原生开发意味着为 iOS 用 Swift、为 Android 用 Kotlin 分别编写应用，这可以带来更好的性能和平台集成，但代价是需要维护两套代码库。Shopify 的举措反映了随着原生工具和 AI 辅助编码的进步，整个行业正在重新评估跨平台策略。

## [Anthropic 指控阿里巴巴、月之暗面与 DeepSeek 发起模型蒸馏攻击](https://techcrunch.com/2026/09/10/anthropic-details-distillation-campaigns-from-alibaba-moonshot-ai-and-deepseek/) ⭐️ 8.0/10

Anthropic 于周四发布报告，指控中国 AI 公司阿里巴巴、月之暗面（Moonshot AI）和 DeepSeek 对其 Claude 模型发起持续且不断升级的模型蒸馏攻击。报告称其中一场攻击涉及约 3500 个账号，被归因于为阿里巴巴 Qwen 系列模型生成训练材料的单一行动，而另一场来自月之暗面的攻击似乎直接路由自中国军方。 这是一家美国主要 AI 实验室罕见地公开指控具名的中国竞争对手，涉及 AI 安全、知识产权保护以及不断升级的中美 AI 竞争。此事可能引发法律、合同或政策层面的回应，并引发关于前沿实验室如何监管其 API 被滥用的更广泛问题。 Anthropic 表示，这些交互分散在约 3500 个不同账号中，但共享同一个用于提取模型思维链的固定提示词，因此被归因于一次协同行动。报告还称月之暗面的攻击似乎直接路由自中国军方，不过摘要中并未详述这些归因背后的技术证据。

rss · TechCrunch · 9月10日 20:57

**背景**: 模型蒸馏是一种机器学习技术，即用更大、更强模型的输出训练一个更小、更便宜的模型，从而以更低成本继承其能力。如果未经授权通过商业 API 进行，这种行为可能构成知识产权窃取，因为强模型的输出被用于打造竞争对手。Anthropic 此前已发布过检测和防范此类蒸馏攻击的研究，而这份报告将相关工作扩展到具名的中国实验室。

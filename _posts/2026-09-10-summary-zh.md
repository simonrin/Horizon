## [OpenAI 声称 AI 解决了纳维-斯托克斯千禧年大奖难题](https://www.theverge.com/ai-artificial-intelligence/992953/openai-math-millennium-prize-navier-stokes) ⭐️ 9.0/10

OpenAI 于周二宣布，其 AI 系统通过构造有限时间奇点，并同时给出解析证明和 Lean 形式化验证，解决了纳维-斯托克斯方程解的存在性与光滑性问题——这是七个千禧年大奖难题之一。该公司表示，如果被授予克莱数学研究所的 100 万美元奖金，他们将拒绝接受，但该结果尚未得到克莱研究所或独立数学界的验证。 如果得到验证，这将是首个借助 AI 解决的千禧年大奖难题，也是自 2010 年庞加莱猜想以来首个新的官方解答，标志着数学研究方式的范式转变。同时，它也引发了关于 AI 在数学发现、证明验证和学术荣誉归属中角色的紧迫问题。 据报道，该 AI 系统同时给出了解析证明和 Lean 形式化验证；Lean 是一种用于机器检查数学论证的证明辅助语言。然而，该结果目前存在优先权争议，尚未得到克莱研究所或更广泛数学界的验证。

## [ShieldCrash Defender 零日漏洞曝光：补丁后仍可 SYSTEM 权限读取文件](https://www.ithome.com/1/000/700.htm) ⭐️ 8.0/10

2026 年 9 月 9 日，匿名安全研究员 Nightmare Eclipse 公开了名为 ShieldCrash 的 Microsoft Defender 零日概念验证漏洞，该漏洞可在 Windows 10、Windows 11 及多个 Windows Server 版本上以 SYSTEM 权限读取任意文件。此次披露恰逢微软发布 2026 年最大 Windows 11 累积更新之后，而该更新仅部分修复了关联的 ShieldBreak 漏洞（编号 CVE-2026-69414）。 这是一起影响重大的安全事件，因为该漏洞绕过了刚刚发布的补丁，并波及 Windows 10、11 和 Server 的庞大用户群。同时，它也凸显了研究员与微软之间围绕漏洞赏金和披露实践的持续争议，这可能影响未来漏洞的修复速度。 根据概念验证，ShieldCrash 与已修复的 ShieldBreak 漏洞（CVE-2026-69414）相关联；微软修复了部分使该问题可被重复利用的条件，但遗漏了一个仍可触发原问题的位置。利用 ShieldCrash 可获得 SYSTEM 权限，这是 Windows 中权限最高的本地账户级别之一，从而能够读取任意文件。

rss · ITHome Feed · 9月10日 04:32

**背景**: 零日漏洞是指尚无官方补丁或安全更新的软件缺陷，因此尤其危险。Microsoft Defender 是 Windows 内置的杀毒与威胁防护组件，而 SYSTEM 是 Windows 系统中权限最高的本地账户。自 2026 年 4 月以来，Nightmare Eclipse 已披露多个零日漏洞，包括 ShieldBreak、LegacyHive、RoguePlanet、BlueHammer、RedSun、YellowKey、GreenPlasma、MiniPlasma 和 UnDefend；微软已修复其中大部分，但部分漏洞仍缺乏官方补丁。

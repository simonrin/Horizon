## [Kakehashi：实验性用户空间在 Linux ARM 上运行 macOS 二进制文件](https://github.com/wie-project/kakehashi) ⭐️ 8.0/10

Kakehashi，一个实验性用户空间项目，成功在 Linux ARM 机器上运行 macOS CLI 二进制文件，并提供了 7-Zip、curl 和 Xcode Git 工具的工作原型。该项目是开源的，可在 GitHub 上获取。 该项目解决了跨平台兼容性中的一个重大技术挑战，可能使 macOS 应用程序无需虚拟化即可在 Linux ARM 设备上运行。它可能为 macOS 软件在非 Apple 硬件上的更广泛采用铺平道路，类似于 Wine/Proton 对 Windows 应用程序所做的那样。 该项目目前通过了 8k 文件树上 7-Zip 的多线程压缩测试，但比原生 Linux 执行慢约 5.2 倍。对于 curl，超过 200 个命令和选项通过了自动化 Docker 测试。该项目仍处于实验性和早期阶段，并已制定优化计划。

hackernews · vlad_kalinkin · 8月2日 16:26 · [社区讨论](https://news.ycombinator.com/item?id=49145937)

**背景**: 由于内核 API、系统库和可执行格式的差异，在 Linux 上运行 macOS 二进制文件历来具有挑战性。像 Darling 这样的项目试图提供兼容层，但 ARM64 支持仍在进行中。Kakehashi 专注于用户空间方法，将 macOS 系统调用和库转换为 Linux 等效项，这可能比完全虚拟化更轻量。

2026 年 8 月 2 日，“2026 新时代生态农业战略研讨会”在新疆乌鲁木齐举行，来自农业、生态、资源环境等领域的中外专家齐聚一堂，围绕生态农业发展的战略方向、生态安全、科技创新和产业落地等议题展开深入研讨。 此次研讨会凸显了可持续农业在中国日益增长的重要性，尤其是在新疆这样的生态敏感地区。讨论可能影响政策和技术采用，进而影响该地区乃至更广泛区域的农业实践和环境保护。 该研讨会由中国新闻社于 2026 年 8 月 2 日报道，邀请了多个学科的专家。具体议题包括战略方向、生态安全、科技创新和产业落地，但简报中未透露具体成果或技术细节。

rss · China News Service China · 8月2日 10:36

**背景**: 生态农业旨在将环境可持续性与农业实践相结合，减少负面影响，同时保持生产力。新疆气候干旱、农业地位重要，在平衡发展与生态保护方面面临挑战。此类研讨会为专家分享知识和提出解决方案提供了平台。

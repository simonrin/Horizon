hackernews · systima · 7月12日 18:25 · [社区讨论](https://news.ycombinator.com/item?id=48883275)

**背景**: 像 Claude Code 和 OpenCode 这样的 AI 编码代理使用大型语言模型来辅助软件开发任务。Token 开销指的是代理的系统提示、缓存机制和工具框架在用户实际提示之外消耗的额外 token。高效的 token 使用对于控制 API 成本至关重要。
